# Database schema

Source of truth: the mapping attributes in `src/Entity/` and the migration
`src/Migrations/Version20260828173000.php` ([Migrations](migrations.md)). Both must stay aligned:
CI checks it ([drift check](migrations.md#drift-check)).

## Relational diagram

```
sylius_channel ── + has_mega_menu                     (MegaMenuChannelTrait)

sylius_taxon ── + 20 columns                          (AdvancedTaxonTrait)
   │
   ├── 1:N  cyllene_advanced_taxon_facet_condition              (taxon_id)
   ├── 1:N  cyllene_advanced_taxon_featured_items_translation   (taxon_id, UNIQUE per locale)
   ├── N:M  cyllene_advanced_taxon_featured_children ── sylius_taxon   (featured_taxon_id)
   ├── N:M  cyllene_advanced_taxon_featured_products ── sylius_product (product_id)
   └── 1:N  sylius_taxon_image ── + 5 columns         (AdvancedTaxonImageTrait)
                 │
                 └── 1:N  cyllene_advanced_taxon_image_translation  (translatable_id, UNIQUE per locale)
```

Every foreign key of the plugin is `ON DELETE CASCADE`: deleting a taxon, product or taxon image
removes its conditions, translations and featured links.

Index and foreign key names are generated by Doctrine DBAL (`IDX_…`, `FK_…`), with the same algorithm
in the mapping and the migration; only the two unique constraints are named explicitly.

Ids of the three plugin entities (`FacetCondition`, `TaxonFeaturedItemsTranslation`,
`TaxonImageTranslation`) are auto-increment columns on MySQL and MariaDB. On PostgreSQL they come
from sequences, as Sylius configures it (`identity_generation_preferences`):
`cyllene_advanced_taxon_facet_condition_id_seq`,
`cyllene_advanced_taxon_featured_items_translation_id_seq` and
`cyllene_advanced_taxon_image_translation_id_seq`.

## Columns added to Sylius tables

All columns are `NOT NULL` unless marked nullable. Defaults are database defaults, identical to the
property defaults of the traits.

### `sylius_channel` (`MegaMenuChannelTrait`)

| Column | Type | Null | Default | Role |
|--------|------|------|---------|------|
| `has_mega_menu` | BOOLEAN | no | `false` | Plugin mega menu rendered for this channel |

### `sylius_taxon_image` (`AdvancedTaxonImageTrait`)

| Column | Type | Null | Default | Role |
|--------|------|------|---------|------|
| `title` | VARCHAR(255) | yes | - | Fallback title (translations take precedence) |
| `url` | VARCHAR(255) | yes | - | Destination link, sanitized ([rules](#write-time-sanitization)) |
| `description` | TEXT | yes | - | Fallback description |
| `position` | INT | no | `0` | Order inside the zone (ascending) |
| `show_card_text` | BOOLEAN | no | `true` | Product-card media: show title and description |

The Sylius `type` column of `sylius_taxon_image` holds the media zone: `main` (main image, also read
for an empty type), `top`, `bottom`, `left`, `right` (product cards), `featured` (spotlight),
`slider_universe` (universe hero slider). These types are reserved: an image of your own with one of
them shows in that zone.

`setTitle()` / `setDescription()` write both the base column and the translation of the current
locale; `getTitleForLocale()` / `getDescriptionForLocale()` return the translation of the given
locale (then current, then fallback locale) and fall back to the base column when it is empty.

## Plugin tables

### `cyllene_advanced_taxon_facet_condition` (`FacetCondition`)

| Column | Type | Null | Role |
|--------|------|------|------|
| `id` | INT, auto-increment (sequence on PostgreSQL) | no | PK |
| `taxon_id` | INT | no | FK → `sylius_taxon(id)` ON DELETE CASCADE, indexed |
| `condition_type` | VARCHAR(32) | no | `attribute`, `option`, `name`, `description`, `stock`, `taxon_membership` |
| `operator` | VARCHAR(32) | no | See the [operator matrix](../domain/conditional-taxons.md#types-and-operators) |
| `reference_code` | VARCHAR(255) | yes | Attribute, option or taxon code |
| `value` | VARCHAR(255) | yes | Compared value (unused by `stock` and `taxon_membership`) |
| `position` | INT | no | Order in the admin (`ORDER BY position ASC` on the collection) |

### `cyllene_advanced_taxon_featured_items_translation` (`TaxonFeaturedItemsTranslation`)

| Column | Type | Null | Role |
|--------|------|------|------|
| `id` | INT, auto-increment (sequence on PostgreSQL) | no | PK |
| `taxon_id` | INT | no | FK → `sylius_taxon(id)` ON DELETE CASCADE, indexed |
| `locale` | VARCHAR(255) | no | Locale code |
| `featured_products_title` | VARCHAR(255) | yes | Featured products block title |
| `featured_products_description` | TEXT | yes | Featured products block text |
| `featured_children_title` | VARCHAR(255) | yes | Featured children block title |
| `featured_children_description` | TEXT | yes | Featured children block text |
| `universe_page_title` | VARCHAR(255) | yes | Universe page title (taxon name when empty) |
| `universe_page_description` | TEXT | yes | Universe page text |
| `universe_featured_products_title` | VARCHAR(255) | yes | Title above the featured products sliders of the children, on the universe page |
| `universe_featured_products_description` | TEXT | yes | Text above the featured products sliders of the children, on the universe page |

Unique constraint `featured_items_translation_uniq` on (`taxon_id`, `locale`). The collection is
indexed by `locale` on the taxon.

### `cyllene_advanced_taxon_image_translation` (`TaxonImageTranslation`)

| Column | Type | Null | Role |
|--------|------|------|------|
| `id` | INT, auto-increment (sequence on PostgreSQL) | no | PK |
| `translatable_id` | INT | no | FK → `sylius_taxon_image(id)` ON DELETE CASCADE, indexed |
| `locale` | VARCHAR(255) | no | Locale code |
| `title` | VARCHAR(255) | yes | Translated title |
| `description` | TEXT | yes | Translated description |

Unique constraint `image_translation_uniq` on (`translatable_id`, `locale`).

### `cyllene_advanced_taxon_featured_children` (`AdvancedTaxonTrait::$featuredChildren`)

| Column | Type | Null | Role |
|--------|------|------|------|
| `taxon_id` | INT | no | FK → `sylius_taxon(id)` ON DELETE CASCADE, indexed |
| `featured_taxon_id` | INT | no | FK → `sylius_taxon(id)` ON DELETE CASCADE, indexed |

Primary key (`taxon_id`, `featured_taxon_id`). The join table has no position column: the featured
children are loaded in their tree order (`sylius_taxon.position`).

### `cyllene_advanced_taxon_featured_products` (`AdvancedTaxonTrait::$featuredProducts`)

| Column | Type | Null | Role |
|--------|------|------|------|
| `taxon_id` | INT | no | FK → `sylius_taxon(id)` ON DELETE CASCADE, indexed |
| `product_id` | INT | no | FK → `sylius_product(id)` ON DELETE CASCADE, indexed |

Primary key (`taxon_id`, `product_id`).

On MySQL / MariaDB the five plugin tables are created in `utf8mb4` / `utf8mb4_unicode_ci`.

## Stored values

### Mode columns

| Column | Values | Constants |
|--------|--------|-----------|
| `featured_products_position` | `before_filters`, `after_filters` | `AdvancedTaxonInterface::FEATURED_PRODUCTS_POSITION_*` |
| `media_display_mode_product` | `products_start`, `products_end`, `products_random_middle` | `AdvancedTaxonInterface::MEDIA_RIGHT_PRODUCTS_POSITION_*` |
| `media_display_mode_top`, `_bottom`, `_left`, `_featured` | `stacked`, `random`; `slider` for top and bottom | `AdvancedTaxonInterface::MEDIA_DISPLAY_MODE_*` |
| `icon_type` | `icon`, `image` | none (admin form choices) |
| `condition_type` | see above | `FacetCondition::TYPE_*` |

The setters of every mode column except `icon_type` replace an unknown value by the default
(`before_filters`, `products_end`, `stacked`); `setIconType()` stores the value as given.

### Icon format

`icon` holds one of:

- `image:<path>`: a pictogram uploaded from the admin, `<path>` being its path in the Sylius image
  storage (`AdvancedTaxonInterface::ICON_IMAGE_PREFIX`). Rendered through the
  `cyllene_advanced_taxon_icon` Liip filter set.
- a glyph name, `name` or `prefix:name`. A name without `:` is rendered as `tabler:<name>` with
  `ux_icon()`.

## Write-time sanitization

`AdvancedTaxonValueSanitizer`, called by the setters, so it applies to every entry point (admin, API,
fixtures, code):

| Setter | Kept | Otherwise |
|--------|------|-----------|
| `setColor()` | trimmed value matching `#[0-9a-f]{6}` (case-insensitive), stored **lowercase** | `null` |
| `setIcon()` | trimmed `image:` + path matching `[a-z0-9_-]+(/[a-z0-9_-]+)*\.[a-z0-9]+`, or a glyph matching `[a-z0-9][a-z0-9:_-]*` (case-insensitive) | `null` (also for an empty value) |
| `setUrl()` (taxon image) | trimmed `http://` / `https://` URL, or a path starting with one `/` not followed by `/` or `\`, without any `\` or control character (tab, line break) | `null` (`javascript:`, `data:`, `//host`, relative paths…) |

Rejected values are dropped silently (no validation error). In the admin form, the color is also
set to `null` when the unmapped **Use a color** checkbox (`hasColor`) is unchecked, since a color
input always submits a value (`#000000` when untouched). Pictogram uploads are restricted
separately (PNG, JPEG, WebP, GIF, 2 MB at most, checked on the content) by `TaxonIconUploader`.
